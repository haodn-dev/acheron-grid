# Acheron Grid

> Spreadsheet UX. Data-grid semantics. Canvas performance.

Acheron Grid aims to be an open-source, framework-independent Canvas Data Grid Engine with spreadsheet-like interactions for React, Vue and vanilla JavaScript.

## Status

Repository foundation only. The engine, public API, adapters and benchmarks have not been implemented. Package publication and license selection are pending.

## Structure

- `packages/core/`: future pure TypeScript engine.
- React/Vue adapters, examples, themes and benchmarks will be added as implementation progresses.

The core will be developed independently of Laravel and frontend frameworks.

## Development

Use `main` for validated changes and short-lived `feat/...`, `fix/...` or `docs/...` branches. Build tooling and checks will be documented when introduced.
